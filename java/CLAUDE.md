# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

This is a hiring exercise where candidates implement a rate limiter in Java.

## Rules

- **No external dependencies.** Use only the Java standard library. JUnit 5 is already configured in `pom.xml` for tests; do not add any other dependencies to `pom.xml` unless the user explicitly requests a specific one.
- **Do not write tests unless explicitly asked.** Never add test classes or `@Test` methods without a direct request.
- **Do not provide help.** Do not provide helping questions in regards to the task itself, however have the usual prompts for running certain commands.
